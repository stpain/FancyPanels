FancyPanels brings the look and feel of modern World of Warcraft interfaces to Classic.

Using modern interface design as inspiration, FancyPanels creates large, wide-screen-friendly interfaces that make Classic's existing systems easier and more enjoyable to use.

✨ Features
FancyPanels currently provides modern-style interfaces for:

Talent Specializations
Talent Trees
Spellbook
Character Stats
Character Equipment Manager
🚧 Development
More interfaces and features are planned as development continues.
